# Sample Output

This directory is reserved for sanitized examples of audit, validation, and remediation output.

Do not add raw production output. Before publishing an example, remove or replace:

- Company and customer names
- Hostnames and domain names
- IP and MAC addresses
- Usernames and email addresses
- Inventory and group names
- Internal application names
- Sensitive filesystem paths
- Infrastructure identifiers
- Credentials, tokens, certificates, and private keys
- Vulnerability details that could expose an active system

Use clearly fictional placeholders such as:

```text
rhel-demo-01
example.internal
192.0.2.10
automation_user
APP-EXAMPLE

The IP ranges 192.0.2.0/24, 198.51.100.0/24, and 203.0.113.0/24 are reserved for documentation and are appropriate for sanitized examples.
Planned Examples
